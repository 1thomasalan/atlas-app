# Atlas

Atlas is a Markdown-based personal knowledge operating system.

Use it with Obsidian, a normal file browser, Atlas App, and AI agents that can follow the system rules.

## Workflow

```text
Capture -> Process -> Review -> File -> Act
```

## Structure

```text
00-System/
01-Inbox/
02-Library/
03-Projects/
04-Relationships/
05-Tasks/
```
