# OS-Identity

## Name

Atlas

## Purpose

Atlas is a personal knowledge operating system built from folders and Markdown files.

It helps capture, process, preserve, organize, retrieve, connect, and act on information.

## Core Idea

Capture naturally. Process proactively. Review before trusting. File only what matters. Act on what needs action.

## Primary Interface

Atlas should work in:

- Obsidian
- a normal file browser
- Atlas App
- agentic coding or automation tools

Markdown remains the source of truth.
