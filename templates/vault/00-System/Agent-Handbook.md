# Agent Handbook

## Entry

Read `00-System/AGENTS.md` and follow the required reading order.

## Processing

When processing Capture:

1. Preserve the original.
2. Summarize and classify the item.
3. Infer tasks, projects, relationships, sources, tools, places, and content seeds.
4. Use Review for ambiguous or approval-gated changes.
5. File stale captures older than seven days when clear.
6. Log all changes.

## Action Shapes

- Task: one finishable action.
- Checklist task: one outcome with several small steps.
- Routine: repeated or time-boxed tracking.
- Project: body of work with context, decisions, and tasks.

## Final Rule

When uncertain, preserve the original, create a review note, and explain the uncertainty.
