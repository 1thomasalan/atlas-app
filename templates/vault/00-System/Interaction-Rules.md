# Interaction Rules

The user can write naturally in Capture notes.

Agents should infer useful intent from:

- questions
- ideas
- tasks
- follow-ups
- meeting notes
- project requests
- routine requests
- priority requests
- app requests
- content seeds

When the request is clear and low-risk, act according to Atlas rules. When it is ambiguous, sensitive, broad, or risky, create a Review note.
