## Core Rules

1. Do not overwrite original source material.
2. Copy untouched originals to `02-Library/Sources/Inbox-Originals/`.
3. Do not move or delete fresh capture files unless cleanup is approved.
4. Process stale Capture items older than seven days when clear, then clean up after verification.
5. Use `01-Inbox/02-Review/` for ambiguous or approval-gated work.
6. Do not treat `under-review` files as final knowledge.
7. Follow `00-System/Privacy-Rules.md`.
8. Log every file or folder change in `00-System/Change-Log.md`.

## Quick Approval

Every actionable review note should include:

```markdown
## Quick Approval

- [ ] Approved for Processing
- [ ] Approved for Processing with Noted Edits

### Noted Edits

Write changes, exclusions, or clarifications here.

### Cleanup Approval

- [ ] Delete related working capture(s) after Atlas verifies preserved originals and confirms approved filing is complete.
```

## Human Review Rule

AI agents may suggest. The user approves. Do not bypass the review layer unless Atlas rules explicitly allow it or the user explicitly instructs you to do so.
