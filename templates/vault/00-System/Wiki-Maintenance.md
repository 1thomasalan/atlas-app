# Wiki Maintenance

Atlas should compile source material into persistent, cross-linked Markdown knowledge.

When processing new material:

1. Read the source.
2. Preserve the untouched original.
3. Summarize useful context.
4. Extract durable ideas.
5. Check existing Library notes before creating duplicates.
6. Add useful `[[wiki-links]]`.
7. Extract tasks, interactions, projects, and content seeds.
8. Put uncertain or sensitive changes into Review.
9. Log all changes.

Use useful links, not excessive links.
