# Object Types

## Default Objects

- Daily notes
- People
- Places
- Tasks

## Optional Objects

- Projects
- Organizations
- Interactions
- Routines
- Sources

Atlas App settings may enable or disable object surfaces without deleting existing Markdown.

## Custom Object Requests

A custom object request should define:

1. Object name
2. What it tracks
3. Processing behavior
4. Ultimate goal
5. Preferred setup processor

Codex or Agent Zero may draft the metadata, destination, template, processing rules, dashboard surface, and relationships. Put the complete proposal in Review before changing durable Atlas rules.

Never store provider credentials or agent connection tokens in an object definition.
